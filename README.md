# 다낭 일지

2026년 10월 2–4일 다낭·호이안 커플 여행용 정적 PWA. 로그인·서버 DB·공금 정산 없이 작동합니다. 이전 이시가키 저장소와는 분리된 새 프로젝트입니다.

## 실행

휴대폰에서는 https://tjdwons123-lgtm.github.io/danang-trip-2026/ 접속. HTTPS 주소이므로 홈 화면에 추가해 앱처럼 사용할 수 있습니다. 로그인은 필요 없습니다.

로컬 미리보기는 Node.js 환경에서 `node server.cjs` 실행 후 http://localhost:4173 접속. 이 주소는 실행 중인 PC 전용입니다.

## 구성

- `data.js`: 일정, 지도 좌표, 장소 후보, 안내 문구. 운영·예약 미확인 상태를 구분합니다.
- 10/4 해산물 점심은 목식당으로 선택했습니다. 공식 예약 링크는 장소 카드에 있으며 Cong Spa 지점이 확정되면 두 장소 사이 이동시간을 다시 확인해야 합니다.
- 공유받은 인스타그램 게시물 5개의 장소·메뉴·쇼핑·입국 정보를 앱의 정보 탭에서 바로 읽을 수 있게 정리했습니다. 원문 링크를 열지 않아도 됩니다. 여행 동선에 맞는 음식점·카페·쇼핑 후보는 장소 탭에 넣었습니다. 2024년 한시장 게시물의 가격표는 현재 가격으로 사용하지 않습니다.
- 입국 정보는 베트남 대사관의 PAI 권장 안내와 베트남 보건부의 건강신고 적용 설명을 우선합니다. 인스타그램의 일괄 의무 주장과 구분합니다.
- `app.js`, `map.js`, `styles.css`: 홈 / 날짜별 지도·일정 / 음식점·카페·마사지 지역 지도 / 개인 예산 / 정보.
- `manifest.webmanifest`, `sw.js`, `icons/`: 홈 화면 설치와 최초 온라인 접속 이후 오프라인 일정.
- 메모와 2인 예상 예산은 브라우저 localStorage에만 저장. 기기 간 동기화되지 않습니다.
- 지도는 Leaflet 1.9.4와 OpenStreetMap 지도로 표시합니다. 지도 선은 장소 사이를 잇는 방문 순서이며 실제 도로 경로나 이동 시간이 아닙니다. Google 지도 링크에서 실제 길찾기를 확인하세요. 위치가 정해지지 않은 가게와 Cong Spa는 정확한 핀으로 표시하지 않습니다.
- 외부 사진·지도·링크는 인터넷 필요. 사진 출처: Vietnam Tourism 공식 관광 페이지. 지도 바탕 출처: © OpenStreetMap contributors. 실시간 기상·환율·영업 데이터는 연결하지 않았습니다.
